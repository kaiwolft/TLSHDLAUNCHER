THE LAST STORY HD - Dionixu's Launcher
======================================

AVISO LEGAL - LEE ANTES DE INSTALAR
  * Este instalador NO incluye el juego. Solo contiene el launcher, las mejoras y las herramientas.
  * Necesitas DOS copias ORIGINALES de The Last Story para Wii, extraidas por ti de tus propios discos:
      - Version americana (NTSC-U, ID SLSEXJ)  -> juego, textos y voces en ingles
      - Version japonesa  (NTSC-J, ID SLSJ01)  -> voces japonesas
  * El instalador comprueba ambas copias (ID y huellas MD5) y SOLO funcionara con tu copia oficial.
    Una copia modificada, incompleta o de otra region sera rechazada.
  * No se acepta ni se fomenta la pirateria. Necesitas tu copia oficial. No descargues el juego de internet.
  * Proyecto de aficionados sin fines de lucro, sin relacion con Nintendo, Mistwalker ni AQ Interactive.

INSTALACION EN LINUX (Debian 12, Ubuntu 22.04, Linux Mint 21 o mas nuevos; 64 bits, sesion X11 o Wayland con XWayland)
  Que necesitas:
    - Unos 13 GB libres.
    - Tus dos copias del juego (.iso, .wbfs, .rvz o .ciso): version americana y japonesa.
    - Tu propio Dolphin para Linux (no se incluye). Recomendado: Flatpak (version actual de Dolphin):
        sudo apt install flatpak
        flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
        flatpak install flathub org.DolphinEmu.dolphin-emu
      Tambien sirve un Dolphin compilado por ti (2412 o mas nuevo; elige dolphin-emu y dolphin-tool en el instalador).
      El paquete 'dolphin-emu' de apt en Debian/Ubuntu suele ser muy antiguo y no se recomienda.
    - Opcional, para el volumen en vivo del menu de pausa: sudo apt install pulseaudio-utils   (pactl)
  Pasos:
    1. Copia esta carpeta completa a tu equipo (por ejemplo a tu carpeta personal).
    2. Abre una terminal en esta carpeta y ejecuta:   bash instalar.sh
       Si faltan bibliotecas, el script te dice que comando apt usar.
    3. Elige el idioma y acepta el aviso legal.
    4. Elige tu Dolphin (se detecta solo si esta instalado) y tus dos copias del juego.
    5. Elige la carpeta de instalacion (por defecto: ~/Games/The Last Story HD) y los accesos directos
       (menu de aplicaciones y escritorio).
    6. Pulsa INSTALAR. Al terminar, el launcher se abre solo en una ventana.
  Que funciona en Linux:
    - Puente del mando: L3 + R3 y Esc abren el menu de pausa, foco de ventanas, ventana sin bordes y volumen en vivo.
    - Motor de logros sin conexion y 60 FPS adaptativo (lee la memoria de Dolphin; no necesita permisos especiales).
    - Mando: cualquier mando compatible con SDL (Xbox, PlayStation, 8BitDo...). Teclado y raton en X11/XWayland.
  Configuracion de Dolphin: se usa una carpeta propia (dolphin-user dentro de la instalacion);
  tu configuracion normal de Dolphin no se toca.
  Desinstalar: borra la carpeta de instalacion y ~/.local/share/applications/the-last-story-hd.desktop.

INSTALLING ON LINUX (Debian 12, Ubuntu 22.04, Linux Mint 21 or newer; 64-bit, X11 session or Wayland with XWayland)
  You need:
    - About 13 GB free.
    - Your two game copies (.iso, .wbfs, .rvz or .ciso): North American and Japanese versions.
    - Your own Dolphin for Linux (not included). Recommended: Flatpak (current Dolphin):
        sudo apt install flatpak
        flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
        flatpak install flathub org.DolphinEmu.dolphin-emu
      A Dolphin you built yourself also works (2412 or newer; pick dolphin-emu and dolphin-tool in the installer).
      The 'dolphin-emu' apt package on Debian/Ubuntu is usually very old and not recommended.
    - Optional, for live volume in the pause menu: sudo apt install pulseaudio-utils   (pactl)
  Steps:
    1. Copy this whole folder to your computer (for example to your home folder).
    2. Open a terminal in this folder and run:   bash instalar.sh
       If libraries are missing, the script tells you which apt command to use.
    3. Pick the language and accept the legal notice.
    4. Pick your Dolphin (auto-detected when installed) and your two game copies.
    5. Pick the install folder (default: ~/Games/The Last Story HD) and the shortcuts (app menu and desktop).
    6. Press INSTALL. When it finishes, the launcher opens in a window.
  Works on Linux: gamepad bridge (L3 + R3 and Esc open the pause menu, window focus, borderless window, live volume),
  offline achievements and adaptive 60 FPS, any SDL gamepad, keyboard and mouse on X11/XWayland.
  Dolphin uses its own folder (dolphin-user inside the install); your normal Dolphin settings are untouched.
  Uninstall: delete the install folder and ~/.local/share/applications/the-last-story-hd.desktop.
